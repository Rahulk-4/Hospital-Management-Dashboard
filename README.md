# 🏥 Hospital Management Dashboard | Excel

## 📌 Project Overview
This project presents an interactive Hospital Management Dashboard developed using Microsoft Excel to analyze healthcare data and monitor hospital performance. It provides insights into patient demographics, department activity, revenue, payment methods, diseases, patient ratings, and waiting times.

## 🎯 Project Objectives
- Analyze patient demographics and visit patterns.
- Monitor department performance and patient volume.
- Analyze hospital revenue and payment methods.
- Track patient satisfaction and waiting times.
- Create an interactive dashboard using Excel slicers and charts.

## 🛠️ Tools & Technologies
- **Microsoft Excel**
- PivotTables and PivotCharts
- Data Cleaning and Preprocessing
- KPI Cards and Data Visualization
- Interactive Slicers and Filters

## 📊 Key Metrics
- **Total Patients:** 40,000
- **Total Doctors:** 80
- **Total Revenue:** ₹61,97,61,405
- **Average Patient Rating:** 4.0/5
- **Average Waiting Time:** 33.7 minutes

## 💡 Key Insights
- ICU has the highest transaction volume.
- Walk-in patients represent the largest patient category.
- Patients aged 46–60 form one of the largest age groups.
- Average patient satisfaction rating is 4.0/5.
- Average OPD waiting time is 33.7 minutes.

## 📂 Project Files
- `HOSPITAL DAHSBOARD 1.xlsx` — Excel dashboard and analysis.
- `HOSPITAL MANAGEMENT DASHBOARD(2).pptx` — Project presentation.

## 🚀 How to Use
1. Download the Excel workbook.
2. Open it in Microsoft Excel.
3. Navigate to the dashboard.
4. Use slicers to filter and explore hospital data.

## ✅ Conclusion
This project demonstrates how Microsoft Excel can transform raw healthcare data into meaningful insights through interactive dashboards, KPIs, and visualizations, supporting hospital performance monitoring and data-driven decision-making.
